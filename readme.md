## Descripción

Este repositorio contiene el material, ejercicios, prácticas y proyectos desarrollados durante la materia **Programación III**.

A lo largo del curso se estudiarán diferentes tecnologías y herramientas utilizadas en el desarrollo web moderno, comenzando con los fundamentos del desarrollo frontend y avanzando hacia tecnologías como **TypeScript, React.js y NestJS**.

---

## Tecnologías y conceptos

### HTML

**HTML (HyperText Markup Language)** es el lenguaje utilizado para estructurar el contenido de las páginas web.

Durante la materia se estudiarán conceptos como:

* Estructura básica de un documento HTML.
* Etiquetas y elementos.
* Formularios.
* Tablas.
* Enlaces e imágenes.
* HTML semántico.
* Estructuración de páginas web.

---

### CSS

**CSS (Cascading Style Sheets)** permite definir la apariencia y presentación visual de una página web.

Se trabajarán conceptos como:

* Selectores.
* Colores y tipografías.
* Box Model.
* Flexbox.
* CSS Grid.
* Diseño responsive.
* Animaciones y transiciones.
* Organización y reutilización de estilos.

---

### JavaScript

**JavaScript** es un lenguaje de programación utilizado principalmente para agregar interactividad y comportamiento dinámico a las aplicaciones web.

Se estudiarán conceptos como:

* Variables y constantes.
* Tipos de datos.
* Operadores.
* Condicionales.
* Bucles.
* Funciones.
* Arrays y objetos.
* DOM.
* Eventos.
* Programación asíncrona.
* Promesas.
* `async/await`.
* Consumo de APIs.

---

### TypeScript

**TypeScript** es un lenguaje basado en JavaScript que incorpora tipado estático y otras características que permiten desarrollar aplicaciones más robustas y mantenibles.

Se estudiarán conceptos como:

* Tipos de datos.
* Interfaces.
* Type aliases.
* Funciones tipadas.
* Clases.
* Herencia.
* Generics.
* Enums.
* Tipado de objetos.
* Configuración mediante `tsconfig.json`.

---

### React.js

**React.js** es una biblioteca de JavaScript utilizada para construir interfaces de usuario mediante componentes reutilizables.

Durante el curso se trabajarán conceptos como:

* Componentes.
* JSX.
* Props.
* State.
* Hooks.
* Eventos.
* Formularios.
* Renderizado condicional.
* Listas.
* Consumo de APIs.
* Manejo de estado.
* Arquitectura de aplicaciones frontend.

---

### NestJS

**NestJS** es un framework para desarrollar aplicaciones backend utilizando Node.js y TypeScript.

Se estudiarán conceptos como:

* Arquitectura de aplicaciones backend.
* Módulos.
* Controladores.
* Servicios.
* Inyección de dependencias.
* APIs REST.
* DTOs.
* Validaciones.
* Manejo de excepciones.
* Conexión con bases de datos.
* Autenticación y autorización.

---
